# GREENSHIP Certification Table

## Homes — Individual donation bands

| Gross floor area | Certification donation |
| --- | ---: |
| Less than 150 m² | On request — contact rating@gbcindonesia.org or sertifikasi@gbcindonesia.org |
| 150–200 m² | IDR 42,000,000 |
| 201–500 m² | IDR 46,000,000 |
| Above 500 m² | IDR 50,000,000 |

The calculator applies the applicable band directly to the home's gross floor area, using the whole-number part of the area to select the band. Below 150 m², no price is shown; the result panel asks the applicant to contact GBC Indonesia.
